# dex-contractDEX AI Control Center

Project Mission

Build an automated multi-agent control center for the DEX legal AI project.

Agent Responsibilities

- ChatGPT: Technical management, architecture and coordination.
- DeepSeek: Independent technical analysis and architecture evaluation.
- Claude: Primary software development and coding.
- Codex: GitHub workflow, code review, testing and change control.
- Human Project Manager: Final approvals and legal domain supervision.

Main Product

An intelligent legal assistant focused initially on Iranian criminal law.

Control Center Responsibilities

1. Agent communication
2. Task assignment
3. Report collection
4. Approval workflows
5. GitHub integration
6. Audit logs
7. API orchestration
8. Security and access control

Security Rules

- Never store API keys in source code.
- Use environment variables and secure secrets.
- Require human approval for sensitive operations.
- Keep agent permissions separated.
